# User Story Specifications

This directory contains the detailed User Story Specifications for the IT Asset Management System. Each file corresponds to a major functional module of the application.

| ID     | Module Name                                              | Description                     | Key Features                              |
| :----- | :------------------------------------------------------- | :------------------------------ | :---------------------------------------- |
| **01** | [Core Platform & API Gateway](./01-core-platform-and-api.md) | Core infrastructure and API.    | Roles, Setup, Master Data         |
| **02** | [Asset Registry & Onboarding System](./02-asset-registry-and-onboarding.md) | Central database of all assets. | Registration, Scanning, Master Data|
| **03** | [Operations & Lifecycle Management](./03-operations-and-lifecycle.md) | Day-to-day asset lifecycle.     | Check-in/out, Maintenance, Status |
| **04** | [Secure Disposal & Compliance](./04-Compliance-Driven%20Disposals.md) | Asset end-of-life management.   | Disposal Requests, Approvals, logs|
| **05** | [Financial Analytics & Automation](./05-financial-analytics-and-automation.md) | Financials and automation.      | Depreciation, Alerts, Reporting   |
